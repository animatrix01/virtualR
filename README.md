# VirtualR - Developer Tools for Virtual Reality

VirtualR is a modern web application that provides a comprehensive suite of tools for Virtual Reality developers. Built with React and powered by Vite, this application offers an intuitive interface for VR development workflows.

## 🚀 Features

- **Drag-and-Drop Interface**: Create VR environments easily with our user-friendly interface
- **Multi-Platform Compatibility**: Build VR applications that work seamlessly across mobile, desktop, and VR headsets
- **Built-in Templates**: Get started quickly with pre-built templates for different VR applications
- **Real-Time Preview**: See your changes instantly with real-time application preview
- **Collaboration Tools**: Work together with your team in real-time
- **Analytics Dashboard**: Track performance and user behavior in your VR applications

## 🛠️ Tech Stack

- **Frontend Framework**: React 19
- **Build Tool**: Vite 7
- **Styling**: Tailwind CSS 3
- **Icons**: Lucide React
- **Linting**: ESLint 9
- **Code Quality**: React Hooks ESLint Rules
- **CSS Processing**: PostCSS 8 with Autoprefixer

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/animatrix01/virtualr.git
   cd virtualr
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 💻 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Run ESLint for code quality
- `npm run preview` - Preview production build locally
